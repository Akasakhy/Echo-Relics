# Echo Relics

Echo Relics adds unusual artifacts whose actions can return later. Version
0.1.0 introduces the Echo Blade.

Strike an enemy, or place a fully charged slash into empty space, and the blade
records where you stood and the direction you faced. A moment later, a
spectral slash cuts through that same space. It does not chase the original
enemy: lure another creature into the recorded area and the echo will hit the
newcomer instead.

## Features

- Server-authoritative fixed-space echo combat
- Multi-target oriented slash volume
- Reverberation I–III for additional echoes
- Accelerando I–III for faster echoes
- English and Japanese localization
- Configurable timing, damage, range, and safety limits
- Dedicated-server and GameTest validation

## Requirements

- Minecraft Java Edition 26.2
- NeoForge 26.2
- Install on both client and server

## Known limitations

- Echoes currently ignore block occlusion and can hit through walls.
- Pending echoes do not persist through logout, death, dimension change, or
  server restart.
- Echoes do not load chunks.
- Vanilla damage invulnerability can reduce closely spaced hits.
